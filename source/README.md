# OYO: UNLOCKED — The Unwritten Reach

Standalone fantasy progression game. Start with START-HERE.md.

The game retains Firebase Spark accounts/progression/community, six adaptive local Guides, nine worlds, 18 missions, 27 boss rounds, UNLOCKED rewards and owner review. This edition adds a distinct visual identity, private Proof Bank with phone offloading, limited tester passes and a separate automatic PayPal payment server.

The active game does not promote or depend on an external course or referral business. No OpenAI API, Cloud Functions or Firebase Storage is used. Images were generated during development, not by the running game. Licensed software dependencies retain their notices.

The PayPal integration is packaged, not live. It requires server hosting, private server settings and sandbox verification. Local service tests use mocks. The Firebase emulator and live integrations were not exercised.

Development: Node 22+, pnpm 11.19.0; `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm build:pages`. For the security suite, install Firebase CLI and supported Java, then `pnpm test:rules`. Billing server deployment is separate; see billing-server/SETUP.md.

Artwork provenance: docs/ASSETS.md. Storage behavior: docs/STORAGE.md. Test evidence and remaining gaps: docs/VERIFICATION.md.
